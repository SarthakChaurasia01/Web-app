# Web-app
A web app that tracks shared expenses in a group and tells everyone who owes whom, and how much.
## Features 
1. Add members: add 2 to 10 people to a group by name. Names cannot be empty or duplicate (case-insensitive). A member can be removed only if they have no expenses.
2.  Add an expense: each expense has a title, an amount (in ₹), who paid, and who it is split among. Split equally among the selected members by default. Amount must be a positive number with at most 2 decimals. Show a clear error message for invalid input. Do not use alert() .
3. Expense list: show all expenses, newest first, with title, amount, payer and split members. Each expense can be deleted. Balances update immediately. 4. Balances: for each member, show total paid, total share, and net balance (gets back or owes). Net balances of all members must add up to ₹0.
